# Foldbird

Foldbird 是一个静态刀版和 3D 样机工作台。可并排查看刀版和样机，调整视角、贴图、灯光及刀模参数，并导出 SVG 或 PNG。

## 运行

以 `dist/` 作为静态站点根目录。可从仓库根目录启动本地预览。

```sh
python3 -m http.server 8080 --directory dist
```

打开 `http://127.0.0.1:8080/`。Three.js 随项目提供，图稿在浏览器内处理。设备缺少 WebGL 时会启用兼容预览。

## 结构与参考图

- 六瓣旋扣盒、枕形盒和斜边翻盖盒按上传的参考图描线，可预览折叠。参考图未标定真实刀版尺寸。
- 其余参考可在结构库查看。瓶身样机可调整直径和标签高度。
- `dist/structure-example.json` 演示如何为自定义结构提供面轮廓、孔位、折线和折叠角度。
